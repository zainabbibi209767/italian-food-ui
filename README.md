🍝 Pasta Landing Page

## ✨ Features

- Elegant UI Design
- Responsive Layout
- Modern Typography
- Clean Food Showcase Section
- Premium Restaurant Aesthetics
- Call-to-Action Buttons
- Minimal and Smooth Interface

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Setup

Clone the repository:

```bash
git clone https://github.com/your-username/pasta-landing-page.git
```

Open the project folder:

```bash
cd pasta-landing-page
```

Run the project by opening `index.html` in your browser.
